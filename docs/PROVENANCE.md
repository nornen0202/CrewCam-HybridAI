# Source and asset provenance

The individual entrant dates the Firebase contest project to November 17, 2026. An earlier cooperative-filming prototype had a repository by November 12 and an Android source import on November 13. This entry reuses the components listed below.

| Origin | What the entry uses |
| --- | --- |
| CrewCam 055 | Visible subject extent and framing deadbands, allocation with minimum adjustment, Nearby star topology, paired camera identity, and Gradle wrapper. The extracted connection code has a dedicated service ID and English status text. |
| New entry | A separate Android package, distributed Firebase inference on each camera, per-request route/source receipts, individual cloud opt-in, generated sample and App Check checks, English capture UI, and a fresh-frame crew state machine. |
| Dependencies | Google Firebase Android SDKs, Google Play services Nearby, AndroidX CameraX, Kotlin, Gradle and Android build tools. Dependencies retain their respective licenses. |
| Fixture | The app draws a ball on a table with Android Canvas from code in SampleCheck. Its known size is available for a framing check. No personal image or external stock visual is required. |

The old 055 take used Galaxy Z Fold8 SM-F971N and S25 Ultra SM-S938N with Nearby, phone-local Gemma and USB production control. Both cameras filmed generated content played on another screen. That result belongs to the prior app and backend. Only evidence collected on the new APK can support a Firebase claim. The bounds support up to eight roles in policy; hardware trials must state the actual number of devices.

The entrant confirmed the right to publish these components under Apache-2.0. This repository starts a separate Git history. Device configuration, signing material, development tokens, camera originals and unedited phone recordings are stored outside this source repository.

Version 0.2 draws on the original SubjectPicker, DirectorInputStrip and DirectorPlanCards interaction designs. Its Android Views implementation binds selections to later full-frame Firebase input, makes Nearby photo sharing optional and displays evidence from the current round. The local rehearsal uses a supplied generated first-birthday video, with two crop windows feeding real on-device Firebase requests. The original movie and locally produced demo edits are excluded from public Git.
